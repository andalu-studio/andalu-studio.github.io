Privacy policy

Andalu and the Andalu Studio tool · Last updated: 6 October 2026

What this is

Andalu is a small studio that makes calm educational videos for young children. To manage its own YouTube channel it uses a private software tool, "Andalu Studio" ("the tool"), that connects to Google services. The tool is used only by the channel owner. It has no other users and collects nothing from viewers.

YouTube API Services

The tool uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's Privacy Policy is at policies.google.com/privacy.

What the tool accesses

With the owner's authorization it can: upload the owner's own videos to the owner's own channel; read the channel's own list of videos and their settings; read the channel's own aggregate analytics (such as views and watch time per day and per video); and send email from the owner's own Google account to the owner (reports and alerts). It does not read email.

What it stores

Authorization tokens, kept only on the owner's computer with access limited to the owner. Aggregate channel analytics and the channel's own video details, kept in a local file and refreshed daily. It stores no personal information about viewers, and none about children.

How the information is used

Only to publish the studio's own videos, to understand which videos are useful so that later videos can be better, and to send the owner status emails.

Sharing

The information is not sold, rented or shared with anyone. It is not used for advertising.

Children

The channel's videos are made for kids. The channel does not ask children for any information, comments are disabled by YouTube's made-for-kids settings, and the tool handles no data about individual viewers.

This website

This site is three static pages. It sets no cookies, has no forms and no analytics. The company that hosts it may keep standard server logs.

Keeping and deleting

Stored data is deleted when it is no longer needed, on the owner's decision, or when the project ends. Access can be revoked at any time at myaccount.google.com/permissions, which stops the tool working.
